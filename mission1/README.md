### AI가 물어서 내가 정한 것:

- 티어 등급 단계 구성

### 같은 행동으로 비교한 결과

- 기획서로 html, css, js로 웹사이트 제작
  - 기대 결과: 영화 티어리스트 제작
    - claude: 직접 svg로 만든 이미지로 영화 포스터를 표기
    - gemini: 현실적인 이미지로 영화 포스터를 표기
- 선택한 파일: gemini
  - 이유: gemini의 ux가 더 마음에 들고, 더 현실적인 이미지로 포스터를 표기해서 눈에 띄었음.

| 파일명 | 고친 내용 | 고친 이유 | 다시 확인한 결과 |

| movie_tier_list_app.html | 반응형, 영화 추가 | 핸드폰 또는 패드 유저에게 좀 더 친화적이게 만들고, 원하는 영화를 추가할 수 있게 만들기 위해 | 정상 작동 |
| movie_tier_list_app.html | 이미지로 저장 | 자신이 만든 영화 리스트를 이미지로 저장하여 쓸 수 있게 만들기 위해 | 정상 작동 |
