# 미션 2 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: Gemini 3 Flash

  - 기록: https://share.gemini.google/6VDxyk6899mb

- 좁혀서 적은 한 문장: 영화 제목에 콜론(:)이나 공백이 포함된 경우 드래그 앤 드롭 데이터(id) 매칭 오류가 발생하고, 미분류(pool) 영역의 렌더링 시 이벤트 리스너가 유실되어 특정 영화 카드의 이동이 불가능했음.
- 좁히려고 해 본 것과 결과:
  - 특정 제목("어벤져스: 엔드게임", "센과 치히로의 행방불명", "토이 스토리") 카드의 드래그 앤 드롭 동작 및 공백 입력 시 반응 확인
  - 카드를 미분류 영역으로 다시 끌어다 놓거나 클릭할 때 이벤트가 동작하는지 테스트함
- AI가 말한 원인과, 그 설명을 직접 확인한 결과:
  - **드래그 앤 드롭 문제**: `card()` 함수에서 DOM 요소를 템플릿 문자열(`template.innerHTML`)로 생성하면서 `data-id` 속성에 콜론(`:`)이나 공백이 포함되어 속성 파싱 및 `dataTransfer` 전송 시 `state.items.find` 검색이 실패함. 또한 `render()` 호출 시 `#pool` 영역의 이벤트 리스너(`wireDrop`)가 재연결되지 않아 미분류 칸으로 이동이 불가능했던 현상을 코드에서 직접 확인함.
  - **공백 검증 문제**: 입력창의 공백 검증 시 유니코드 공백 처리 및 `alert` 경고 창 처리가 누락되어 있었음을 확인함.
