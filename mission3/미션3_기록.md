# 영화 티어리스트 피드백

## 1. 잘된 점

- **진행 상황 실시간 표시**: 영화를 옮길 때마다 `8편 중 X편 나눔` 상태가 바로 바뀌어 편리함.
- **드래그 시 시각 피드백**: 카드를 잡고 등급 칸에 올리면 칸 배경색이 달라져 위치를 알아보기 편함.
- **클릭 조작 지원**: 드래그뿐만 아니라 카드와 등급 배지를 차례로 눌러 옮길 수도 있어 접근성이 좋음.

---

## 2. 고치면 좋을 점

### ① 파일 재오픈 시 데이터 미저장

- **현상**: 카드를 S칸에 옮겨도 새로고침하거나 다시 열면 미분류로 리셋됨.
- **기준**: 기획서 완성 기준 (다시 열어도 남아야 함)
- **제안**: `localStorage`와 같은 새로고침 전 위치 상태를 저장 필요.

### ② 모바일 화면 잘림 현상

- **현상**: 화면 폭이 좁을 때(400px 이하) 오른쪽이 잘리고 가로 스크롤이 생깁니다.
- **기준**: 기획서 완성 기준 (화면 폭이 좁아져도 안 잘림)
- **제안**: CSS의 `.page` 너비를 `width: 960px`에서 `max-width: 960px; width: 100%;`로 수정해 주세요.
